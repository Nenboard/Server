Server is a program for running an HTTP server, written in C++ using winsock and wininet library. 
The default port is 8000. 
It is recommended to run it as an administrator. 
You need to save your page in the index.html file. 
You can also block users by writing their IP address in the ips.txt text file. 
After running the program, all information from the console is saved in the log.txt text file. 
The console displays new connections and the port when the program starts.
