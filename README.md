Made by Nenboard.
This program starts a server for websites.
There is no support for the Russian language!!!

How to run:
1. Write your website in the index.html file in the program's root folder.
2. Run the program using a shortcut on your desktop or through the console.
3. If you run the program through the console, specify the server port in the command-line arguments.
4. All user connections will be displayed in the console and in the log.txt file in the root folder.
5. You can also block users. To do this, write the user's IP address in the ips.txt file.

How to connect:
1. Write the IP address in the browser and go to it.
2. After that, the website that was uploaded to the server will be visible on the browser page.
3. If you are unable to access the website, it is likely that you have poor internet connection or have been blocked.

For admins:
1. To send a message to the server, use XMLHttpRequest.
2. To send a message to a client, make a request ("~") to the server. After that, the server will send the previous message
